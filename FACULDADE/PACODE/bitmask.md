# Bases numéricas:
- Qualquer número pode ser representado como a soma de potências de uma base *b* - em base binária (b = 2), cada dígito a é 0 ou 1.
	- N = a1 x b^k + ... + a0 x b^0; 
- Dentro disso, usaremos complemento de 2 para representar números negativos em binário;
- Em C++, usamos `>>` para dar shift em bits (`x >> 3` é a mesma coisa que `x / 8`, ou seja, `x / 2³`);k

| Símbolo | Notação C++ |
| :-----: | :---------: |
|   AND   |      &      |
|   OR    |     \|      |
|   XOR   |      ^      |
