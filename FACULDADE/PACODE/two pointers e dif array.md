# Lógica: two pointers

- Problema-base: temos um array e precisamos descobrir que elementos dele somados dão um certo resultado;
- Usamos dois ponteiros em um array ordenado, a fim de testar resultados e de encontrar a soma desejada;
- Se a soma der menor, o ponteiro l vai um para frente, enquanto, se a soma der maior, o ponteiro r vai um para trás;
