também chamados de vetores, arranjos...

são uma variável estruturada, ou seja, têm mais de um componente.
- homogêneos, ou seja, contêm uma coleção de variáveis do mesmo tipo;
- cada componente é um elemento;
- começam no índice 0.

(se fosse heterogêneo, teria uma coleção de variáveis com algum tipo diferente)

sintaxe:
- int NOME[5] = em que 5 é o número de elementos;
- cada elemento tem um índice, começando de 0 até n-1 (sendo int NOME[n]);
- para referenciar índices: NOME[2] = 7 (no índice 2, há o int 7);
