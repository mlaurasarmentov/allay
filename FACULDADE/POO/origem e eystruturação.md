
### Compilação:
- Cria um artigo executável: não precisa de um código fonte, só do executável.
	código fonte -> código objeto -> código executável -> execução

### Interpretação:
- Linha a linha
	código fonte -> execução

### Abordagem híbrida:
	código fonte -> bytecode -> execução
- Entre 1 e 2, há uma análise léxica e uma sintática.
