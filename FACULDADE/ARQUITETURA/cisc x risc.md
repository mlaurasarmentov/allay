# Cisc:

- Instruções pequenas e objetivas, pois a microprogramação (programas pré-escritos no hardware do computador) já resume códigos robustos;
- Modo de endereçamento complexo: várias instruções podem acessar a memória para os seus próprios fins;
- Muitas instruções por ciclo.

# Risc:

- Instruções maiores, com várias linhas de código para uma tarefa e mais controle do programador. Porém, seus códigos são mais complexos;
- Somente Load e Store acessam a memória;
- Uma instrução por ciclo de clock;
- Pipelining.
