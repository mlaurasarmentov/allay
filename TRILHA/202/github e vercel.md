## Github:
- Pasta x Repositório:
	- Pasta guarda somente no computador;
	- Repositório salva mudanças a partir de uma linha do tempo, ou seja, diferentes versões.
	- O github, com uma cópia do repositório, guarda as informações fora da máquina.
- Commit: salva uma foto do projeto no seu repositório, com uma mensagem - funciona em corrente, cada commit salva o projeto todo em ordem crónológica, de modo que eles são encadeados;
- Push: manda para os servidores do github, ou seja, para uma cópia remota do repositório, seja pública ou privada;
- Sobra no github somente o que foi empurrado (conteúdo do último push).

## Vercel:
- Como o github apenas guarda o código, precisa-se de algo que sirva esse código para um internauta, ou seja, deixe, por exemplo, o site acessível;
- Usa-se um computador ligado para deixar o código sempre online: esse conceito é a hospedagem (no caso, para hospedagem, usaremos a vercel);
- Sempre que chega um push, a vercel pega a nova foto do push, prepara a página e publica (agentes só dão push caso sejam pedidos);
- Deploy: ato de pôr uma versão de um site no ar;
- Para saber se uma mudança chegou no site, abre-se seu link público, não a versão de uma máquina;
